# TODO 리스트 앱 프로젝트

## 프로젝트 목표

Vue.js 프레임워크를 학습하기 위해 할 일 목록을 관리하는 TODO 리스트 관리 앱을 구현합니다.
Vue3의 Composition API를 이용합니다.

## 구현 목표

1. 투두 아이템 생성

내용을 입력하면 해당 내용을 기반으로 투두 아이템 객체를 생성합니다.
투두 아이템은 ID, 할일, 완료여부, 종료일, 생성일을 속성으로 가집니다.
투두 아이템을 생성하면 투두 리스트에 아이템을 추가합니다.

2. 투두 아이템 출력

현재 생성된 투두 리스트를 기반으로 페이지에 각 투두 아이템의 정보를 리스트뷰 형태로 출력합니다.
투두 리스트에는 필터링을 적용하여 전체, 완료, 미완료 필터에 해당하는 조건의 투두 목록을 리스트뷰로 출력할 수 있어야 합니다.

3. 투두 아이템 상태 변경

기존에 생성된 투두 아이템을 수정/삭제할 수 있는 인터페이스를 제공하고 그에 맞게 아이템 상태를 수정해야 합니다.

- 투두 완료 : 투두 완료를 클릭하면 투두의 완료 속성이 업데이트되고 완료/미완료 상태가 출력돼야 합니다.

- 투두 수정 : 투두 수정 버튼을 클릭하면 투두의 할일, 종료일 속성을 변경할 수 있어야 합니다.

- 투두 삭제 : 투두 삭제를 클릭하면 해당 투두 아이템이 전체 투두 목록에서 제거돼야 합니다.

## TodoTodo v1.0.0

### 투두 목록

- 페이지 중앙에 는 투두 리스트뷰가 위치하여 현재 투두 목록에 들어있는 투두 아이템들이 수직으로 나열됩니다.

- 투두 아이템에는 완료, 할일, 진행상태, 수정/삭제 항목이 존재합니다.

- 완료를 클릭하면 해당 아이템의 상태가 완료로 바뀌며 진행상태 항목의 아이콘을 통해 현재 상태를 확인할 수 있습니다.

- 할일 항목에는 아이템에 입력한 할일이 출력됩니다.

- 종료일에는 사용자가 입력한 종료일이 yyyy년 M월 d일 HH:mm PM/AM 형태로 출력합니다.

- 수정/삭제 항목에는 수정 버튼, 삭제 버튼이 존재합니다. 수정 버튼을 클릭하면 아이템을 수정할 수 있는 모달이 나타납니다. 확인을 클릭 시 수정이 반영되며, 취소 클릭 시 모달이 닫히고 변경을 진행하지 않습니다.

  삭제 버튼을 클릭하면 해당 아이템이 즉시 투두 리스트에서 삭제됩니다.

- 투두 리스트뷰 위에는 리스트뷰에 출력될 투두 아이템들을 필터링할 수 있는 필터 탭이 있습니다. 필터 종류는 전체, 미완료, 완료가 있습니다.
  - 전체 필터 : 현재 존재하는 모든 투두 아이템들을 출력합니다.
  - 미완료 필터 : 현재 완료 상태가 아닌 투두 아이템들을 출력합니다.
  - 완료 필터 : 현재 완료 상태인 투두 아이템들을 출력합니다.

### 투두 입력창

- 투두 입력창에서 날짜, 시간, 할일 내용을 입력한 후 등록하면 목록에 투두 아이템이 추가됩니다. 할일 내용이 공백이거나, 입력한 종료일이 현재 시간보다 한 시간 이내인 경우 경고 메세지를 출력하고 아이템 등록이 거부됩니다.

- 투두 입력창은 sticky 형태로 구현하여 스크롤해도 화면을 따라 이동합니다.

### 투두 리스트 저장

- 브라우저를 새로고침할 때마다 투두 리스트가 초기화되는 것을 방지하기 위해 브라우저의 로컬 스토리지를 이용한 투두 리스트 저장 기능을 구현했습니다.

- 투두 리스트에 대한 생성, 수정, 삭제가 발생할 때마다 TodoStore에 관련된 변경 작업을 함께 요청합니다. TodoStore에서는 요청이 들어오면 지정된 키값으로 로컬 스토리지에 현재 투두 아이템 목록을 JSON 형태로 변환하여 저장합니다.

- 투두 리스트 컴포넌트를 setup할 때 TodoStore에서 이전에 저장된 투두리스트 JSON을 다시 투두아이템 배열로 변환하여 출력합니다.
